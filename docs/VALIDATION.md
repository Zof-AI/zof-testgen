# Validation and release evidence

Run `npm run check` for strict TypeScript compilation plus named unit, integration, end-to-end and security tests. Run `npm run test:package` to build a tarball, install it into a temporary clean project with scripts disabled, load the public package exports and invoke the installed CLI. Tests use synthetic local fixtures, never customer data or hosted endpoints.

File operations support Node 22/24 on Linux/macOS with Python 3.10 or later; Windows file operations fail closed. Only completed CI jobs verify their declared platforms. Local candidate validation is separate from anonymous public installation, registry ownership, protected release settings and independent security/QA review. Missing evidence remains unverified.

Ollama acceptance tests exercise the documented HTTP protocol against a controlled ephemeral loopback fixture, including no-consent behavior, fixed request shape, source minimization, output validation, deadlines, redirects, malformed data and packaged API/CLI invocation. They do not run a language model. A separate isolated Ollama 0.13.5 / qwen2.5-coder:0.5b trial confirmed transport/schema/syntax compatibility but failed generated-test execution because both candidates used unimported Jest globals. Both defective and corrected fixtures failed, so the trial does not establish successful regression detection.

The strengthened prompt and framework guard were exercised with real Ollama 0.13.5 and `qwen2.5-coder:1.5b` (model manifest SHA-256 `d7372fd828518a4d38b1eb196c673c31a85f2ed302b3d1e406c4c2d1b64a0668`). The unmodified generated candidate imported `node:test`, strict assertions and the selected synthetic increment module. It retained both supplied oracles. In pinned Node 22 containers it failed the buggy function with an assertion failure and passed the corrected function, with the same candidate SHA-256 `191b8249be024c41de8dbb104287b79d9aa0d99f7ed2c13e9e59faf5f3cfbc7a`. This is one measured TypeScript example, not a model-wide correctness claim. Python live-model behavior and other model/runtime combinations remain unverified.
